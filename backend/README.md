# Backend

See the project [README](../README.md) for MongoDB configuration, startup, first-admin seeding, and sandbox checkout limitations.

Useful commands from this directory:

- `npm install` — install dependencies
- `npm run dev` — start the API and static customer/admin sites after MongoDB connects
- `npm start` — start without the development file watcher
- `npm run seed:admin` — create the first administrator (one-time)
- `npm run check` — check server and route JavaScript syntax
